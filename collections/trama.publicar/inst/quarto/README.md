# Extensão quarto-live vendorizada

`_extensions/r-wasm/live/` é a extensão [quarto-live](https://github.com/r-wasm/quarto-live)
na tag **v0.2.0** (WebR 0.6.0), copiada arquivo por arquivo da tag em 2026-10-19,
com o `LICENSE.md` (MIT, "quarto-live authors"). O `_extension.yml` da tag diz
`version: 0.1.3-dev`; vale a tag.

Fixada de propósito: a página publicada não pode mudar porque a extensão mudou.
Para atualizar, troque a pasta inteira por outra tag e suba
`.TR_PUBLICAR_QUARTO_LIVE` em `R/montar.R`.
