# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todos com respeito, aceite crítica construtiva, foque no que
é melhor para a comunidade e não tolere assédio de nenhuma forma.

Casos de comportamento inaceitável podem ser relatados ao mantenedor, Pedro
Mambelli Fernandes, em pedromambelli@gmail.com. Toda denúncia será analisada
com sigilo.
