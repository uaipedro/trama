# Vocabulário do trama

## Documentação

| Termo | Definição |
| --- | --- |
| Conteúdo principal | Explicação canônica de uma página: precisa, direta e completa sem depender de uma trilha alternativa. |
| Camada facilitadora | Material adicional e opcional que fornece o contexto prévio necessário para acompanhar o conteúdo principal. Não é uma versão simplificada dele. |
| Leitor | Pessoa que aprende ou consulta o trama, qualquer que seja sua bagagem prévia. |
| Organização do pensamento | Efeito central pretendido pelo trama: tornar visíveis dados, transformações, relações e próximos passos para que a pessoa possa conduzir o próprio problema. |
| Progressão sem troca de ferramenta | Princípio de produto pelo qual a primeira experiência é simples, mas o mesmo trama revela recursos e rigor adicionais conforme a bagagem da pessoa cresce. |
| Raciocínio à vista | Horizonte de linguagem para a capacidade de explicitar o procedimento, as escolhas e os resultados de uma análise. Não significa que o trama infere ou substitui o raciocínio da pessoa. |

## Canvas

| Termo | Definição |
| --- | --- |
| Papel | O que um bloco faz no fluxo, na ordem do analista: origem, preparação, inspeção, ajuste, leitura, avaliação, saída. Define a cor do cabeçalho do card. Ver `docs/linguagem-visual.md`. |
| Ajuste | Papel do bloco que constrói um objeto de análise (modelo, decomposição, PCA). |
| Leitura | Papel do bloco que lê um ajuste já existente (quadro da ANOVA, coeficientes, previsões). Não é "análise" genérica: sem ajuste de onde sair, o bloco é inspeção. |
| Tomada | A porta do card como aparece no canvas; a cor dela é a do tipo que passa pelo fio. |
